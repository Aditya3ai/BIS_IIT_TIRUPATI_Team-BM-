How to run the BIS Retriever UI (Local)

Team: BM@% — IIT Tirupati Hackathon (Sigma Squad)

  1. Install Python 3.11+ and create a virtual environment at project root.
  2. Activate the venv and install dependencies:
    \.venv\Scripts\python.exe -m pip install -r requirements.txt
\.venv\Scripts\python.exe -m pip install -r requirements-ui.txt
  3. Run the UI server:
    \.venv\Scripts\python.exe ui\app.py
  4. Open http://127.0.0.1:5000 in a browser and enter a query.
  5. To evaluate results with the same evaluator used in the hackathon, run the evaluator endpoint or directly run:
    \.venv\Scripts\python.exe eval_script.py --results data\results\final_judges_test.json

Rules & Notes

  • Pre-built indexes are included in data/index/; no rebuild needed.
  • Do not commit .env or .venv/.
  • If the server fails to start because of index loading time, wait a few seconds and refresh; large indexes may take time to load on first import.
